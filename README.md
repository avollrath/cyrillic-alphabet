# Cyrillic Alphabet

Eine einfache React-App zum Lernen des russischen Alphabets.

![Vorschau der App](./docs/app-preview.jpg)

## Was die App kann

- Buchstaben des russischen Alphabets im Quiz üben
- Antworten direkt prüfen
- Fortschritt, Punkte und Erfolge lokal im Browser speichern
- Lernstand im Bereich Fortschritt ansehen

## Technik

- React
- TypeScript
- Vite
- Tailwind CSS

## Entwicklung starten

```bash
npm install
npm run dev
```

## Produktionsbuild

```bash
npm run build
```

## Hinweis

Der Lernstand wird lokal im Browser gespeichert. Es gibt keine Anmeldung und kein Backend.
